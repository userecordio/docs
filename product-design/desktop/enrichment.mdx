Enrichment collects work, location, shift and salary details from candidates already in a customer's database. Answers are self-reported and not verified.

## Components used

| Figma component | shadcn/ui | Where |
| --- | --- | --- |
| Table, Data Table | `table` (+ TanStack Table for data tables) | Enrichment list, candidates, campaigns |
| Button | `button` | All steps |
| Badge | `badge` | Status in tables |
| Tabs | `tabs` | Create campaign, analytics |
| Input | `input` | Create enrichment, new campaign |
| Checkbox | `checkbox` | Row selection, setup options |
| Progress | `progress` | Campaign and response progress |
| Dropdown Menu | `dropdown-menu` | Row three-dot menu |
| Pagination | `pagination` | Tables |
| Charts | `chart` | Analytics |

```bash
npx shadcn@latest add table button badge tabs input checkbox progress dropdown-menu pagination chart
```

<Note>
  The six-tab bar inside an enrichment is **Tab Nav Links** from Pro Blocks, and the **Composer** in the result view is custom. Neither is a shadcn/ui component.
</Note>
