This is the single source of truth for how Record looks and is built: the tokens, the components, and every product screen, taken from our Figma file **Infra Design – Record**.

## What it's built on

<Columns cols={3}>
  <Card title="shadcn/ui" icon="component">
    Every component is a shadcn/ui component. Add it with the shadcn CLI and use it as-is, or with our variants.
  </Card>

  <Card title="Tailwind CSS" icon="wind">
    Spacing, sizes, radius, type and colours are standard Tailwind tokens, plus Record's brand colours.
  </Card>

  <Card title="Figma" icon="figma">
    Tokens are exported from the Figma variables collection. Figma is the source; this site mirrors it.
  </Card>
</Columns>

## How to use this site

<Steps>
  <Step title="Set up once">
    Follow [Installation](/product-design/installation) to add shadcn/ui and the Record tokens to your project.
  </Step>
  <Step title="Build with tokens, not raw values">
    Use Tailwind classes (`bg-primary`, `p-4`, `rounded-lg`) or the semantic CSS variables. Don't paste a hex code or pixel value into a component.
  </Step>
  <Step title="Pick components from the library">
    Each component page has a preview, the install command, usage code and the tokens it uses.
  </Step>
  <Step title="Match the screen">
    Open the screen page for the feature you're building. It shows the design, the components on it and a link to the Figma frame.
  </Step>
</Steps>

<Tip>
  If code and Figma disagree, Figma wins. Tell the design team so this site gets updated too.
</Tip>
